AssessMe Word Add-in - Help Center

🧭 What is AssessMe?

AssessMe helps educators track and log student writing activity in Word. It uses secure encryption and automatic logging features embedded directly into the document header.

📥 Installing the Add-in

  1. Download or deploy the AssessMe Word add-in via Microsoft AppSource or directly using the manifest.
  2. Open Microsoft Word and go to the Home tab.
  3. Click Open AssessMe Pane to start logging.

🔒 Logging & Encryption

Your writing activity is saved in secure encrypted format inside the Word document using XML. The system captures diffs, full snapshots, and metadata about the editing session.

⚙️ Logging Intensity

Use the dropdown menu in the task pane to set how frequently changes are saved:

  • High: every 10 seconds
  • Medium: every 30 seconds
  • Low: every 60 seconds

❓ Troubleshooting

  • 🔌 No status banner? Ensure the add-in has loaded fully in the Word task pane.
  • 🛑 Red error banner? Indicates a logging failure — try reloading the pane.
  • 🧾 No log entries? Make sure the document header includes student info fields.
